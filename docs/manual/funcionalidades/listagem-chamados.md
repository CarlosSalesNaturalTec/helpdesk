# Listagem e filtros de chamados

A tela **Chamados** lista os chamados dentro do seu escopo — os seus próprios, para o Solicitante; os da sua Unidade (e, para Técnico e Gestor, do seu Tipo de Ocorrência) para os demais perfis; todos, para o Administrador.

## Filtros disponíveis

- **Busca** por título, nome do solicitante ou nome da Unidade.
- **Tipo de Ocorrência.**
- **Urgência** — Baixa, Média, Alta ou Crítica.
- **Status** — clique em um ou mais status para combiná-los; a listagem mostra os chamados que estejam em **qualquer** um dos status marcados. Nenhum status marcado equivale a "todos". O botão **Limpar** desmarca todos de uma vez.
- **Unidade** — apenas para o Administrador.

Os filtros se combinam entre si: por exemplo, urgência Crítica com os status Aberto e Reaberto mostra só os chamados críticos em um desses dois status. O total de chamados encontrados, logo acima da lista, reflete todos os filtros aplicados.

## Filtros no endereço da página

Os filtros ativos ficam gravados no endereço da página. Isso permite:

- **Recarregar** a página sem perder os filtros.
- **Voltar** com o botão do navegador para o filtro anterior.
- **Compartilhar** o endereço com um colega para que ele veja a mesma listagem filtrada.

Quem abre um endereço compartilhado continua vendo apenas o que o seu perfil permite. Um filtro de Unidade que venha no endereço só é considerado para o Administrador; para os demais perfis ele é ignorado e vale sempre a própria Unidade (e, para Técnico e Gestor, o próprio Tipo de Ocorrência).

## Chegando pelo Dashboard

Os cartões do [Dashboard](relatorios-dashboard.md#dashboard) levam direto a esta tela, já filtrada pelo mesmo critério usado na contagem do cartão — a quantidade de chamados encontrados é igual ao número exibido no cartão.
